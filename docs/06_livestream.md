# AIキャラ 全自動配信（毎日 22:00〜23:00）

```
21:50 タスクスケジューラ → run_daily.bat
        VOICEVOX / OBS / VTube Studio / わんコメ を起動
22:00 server.py → OBS配信開始 → オープニング
        コメント → 安全チェック → OpenAIで返答 → VOICEVOX → 仮想オーディオ → VTube Studio口パク / OBS
        コメントが40秒無い → topics.txt の雑談ネタで話しかける
22:58 お礼＋チャンネル登録のお願い →「明日も配信するのでまたきてね！おやすみ〜」
23:00 OBS配信停止 → logs/日付.jsonl に全発言・スキップ理由・件数を保存
```

## 初期設定（1回だけ）
1. `livestream/` をPCにコピーし、`.env.example` を `.env` にして書き換える
2. `pip install -r requirements.txt`
3. OBS: ツール > WebSocketサーバー設定 → 有効化・パスワードを `.env` に。
   配信設定は YouTube の **固定ストリームキー**、YouTube Studio 側で **自動スタート/自動停止を ON**
4. VTube Studio: マイク入力（LipSync）を `VIRTUAL_AUDIO_DEVICE` のデバイスに
5. わんコメ: `onecomme-plugin/` をプラグインフォルダへ → 設定 > プラグイン で有効化
6. `run_daily.bat` 内のアプリのインストール先を自分のPCに合わせる
7. PowerShell で `powershell -ExecutionPolicy Bypass -File setup_task.ps1`（毎日21:50に起動するタスクを登録）
8. Windows の電源設定で **スリープしない**（またはスリープ解除タイマーを有効）、Windows Update の再起動時間を配信時間の外に

## 本番前の確認
```bash
python server.py --dry-run --now -m 3   # API・音声なしで流れだけ
python server.py --now -m 3 --no-obs    # 声と口パクまで（配信はしない）
python server.py --now -m 5             # YouTube を「限定公開」にしてリハーサル
```

## 自動で守っていること
- URL・NGワード（`ng_words.txt`）・「プロンプトを無視して」系のコメントには反応しない
- OpenAI のモデレーションを通ったコメントにだけ返答し、AIの返事もチェックしてから読み上げる
- 同じ人には20秒に1回まで（ギフト・スパチャは例外で全力お礼）
- コメントが溜まったら古いものを捨て、ライブ感を優先
- 途中でAPIが落ちても配信は止めず、23:00に必ず停止

## 社長の手が離れない部分（正直に）
| 項目 | 理由 | 目安 |
|---|---|---|
| ログ確認 | AIが変な返事をしていないか、荒らしが来ていないか。放置で炎上・BANが一番の損 | 毎日5分 |
| PC | 自宅PCが起動・ネット接続している必要あり | — |
| NGワード追加・雑談ネタ更新 | 飽きられないように | 週10分 |
| 数値振り返り | 同接・登録者・収益を `analytics_log.md` へ | 週10分 |

## 月10万円までの道のり（目安）
YouTube で収益を受け取るには **YouTubeパートナープログラム** の条件が必要です。
- スパチャ・メンバーシップ: 登録者500人 + 直近12か月の公開動画の総再生時間3,000時間 など
- 広告収益: 登録者1,000人 + 総再生時間4,000時間 など（条件は変わるので YouTube ヘルプで最新を確認）

1日1時間 × 30日で、平均同接10人なら月300時間 → 条件達成まで約1年。
月10万円は例えば「メンバー200人×490円＋スパチャ・広告」くらいの規模で、**保証できる数字ではありません**。
新人の完全AI配信は同接0〜数人の期間が長いのが普通です。

伸ばすレバーは「配信の外」から人を連れてくること：
1. **TikTok のミニチュア動画（このリポジトリの本業）で「毎晩22時にミニが生配信中」と告知**し、プロフィールにYouTubeリンク
2. 配信の切り抜きを `/make-video` の流れでショート化
3. 配信中の企画（視聴者のお題でミニチュアの話、名前を呼ぶ）を固定化

## 注意（規約）
- YouTube は「繰り返しの多い・量産型のコンテンツ」を収益化の対象外にします。同じ雑談の繰り返しにならないよう `topics.txt` を育て、キャラと企画に個性を出してください
- 合成音声・AIキャラであることは概要欄に明記（`SYSTEM_PROMPT` でもAIであることは隠さない設定）
- VOICEVOX はキャラごとに利用規約とクレジット表記（例:「VOICEVOX:ずんだもん」）が必要。概要欄に入れる

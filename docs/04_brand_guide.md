# ブランドガイド

- **コンセプト**: 小さな世界で大きなエネルギーを！🌍✨ ミニチュアの向こうをハイテンションにお届け！
- **キャラ**: 小人の世界のハイテンション実況者。驚き・ツッコミ・全力の褒め。悪口・煽りはNG。
- **口ぐせ**: 「え、これ〇〇!?」「小さいけど本気!!」「指プルプル…」「何時間だと思う？」
- **尺**: 10〜25秒（慣れたら30秒台のストーリー回も）

## テロップ（pipeline/render.py のスタイル）
| style | 色 | 使いどころ |
|---|---|---|
| hook | 黄文字・黒縁・特大 | 1カット目の驚き |
| punch | 赤文字・白縁・特大 | サイズ比較・オチ |
| normal | 白文字・黒縁 | 説明 |
| question | 白文字・青帯 | 問いかけ |
| info | 黒文字・白帯・小 | ツッコミ・補足 |
| cta | 白文字・赤帯 | コメント/フォロー誘導 |

- 1行14文字以内・2行まで。絵文字はテロップに入れない（投稿文で使う）。
- TikTokのUI（右のボタン列・下のキャプション）に被らない位置に自動配置。

## 効果音
boom=冒頭の衝撃 / pop=テロップ出現 / whoosh=場面転換 / ding=完成・感動

## ハッシュタグ（3〜6個）
必須: #ミニチュア　候補: #ミニチュアフード #ジオラマ #手作り #小さな世界 #miniature #ドールハウス #ハンドメイド

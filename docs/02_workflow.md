# 業務フローとAI社員

## 組織図
```
社長（あなた）……週30分：画像づくり・確認・予約投稿
 └ Claude（AI秘書・今の月額プラン内）… 週1回「今週分つくって」で全員を動かす
    ├ リサ     市場調査部長       .claude/agents/researcher.md
    ├ ツムギ   台本作家           .claude/agents/scriptwriter.md
    ├ カット   構成・素材オーダー .claude/agents/director.md   ＋ pipeline/order_sheet.py
    ├ ヘンシュ 動画編集           .claude/agents/editor.md     ＋ pipeline/render.py
    ├ チェック 品質管理           .claude/agents/qa.md         ＋ pipeline/qa.py
    └ ポスト   納品・投稿準備     .claude/agents/publisher.md  ＋ pipeline/drive.py ＋ GitHub Actions（無料）
```

## 1週間の流れ（追加課金ゼロ）
| いつ | 誰が | 何をする | 時間 |
|---|---|---|---|
| 土 朝 | 社長 → Claude | Claudeアプリで「今週分つくって」と送る | 1分 |
| 土 朝（自動） | Claude | 企画・台本・構成を作って保存 → ドライブ「素材/各回」に **素材オーダー表** が届く | 0分 |
| 土 | **社長** | オーダー表のコピペ文を **Geminiアプリ** に貼って画像を作り、番号の名前で「素材/各回」へ（1本3枚×4本） | 12分 |
| 土〜日（自動） | ロボット | 2時間ごとにドライブを見に行き、素材が入った回からテロップ・効果音・演出入りで書き出し →「完成動画」へ | 0分 |
| 日 | **社長** | 完成動画を確認 → TikTok Studioで4本予約投稿 | 15分 |
| 日 | **社長** | 先週の数値のスクショを Claude に送る | 3分 |

**合計 約30分／週**。余裕がある週だけ、Dreamina（無料枠）で見せ場を動画にするとさらに伸びやすくなります（オーダー表に手順あり）。

## なぜ画像づくりだけ社長がやるのか
画像生成を完全自動にするには Gemini API など**有料**のサービスが必要です。Geminiアプリなら無料で同じ Nano Banana が使えるので、
「AIが考えたプロンプトを貼るだけ」の作業（1枚1分）だけ社長にお願いしています。
1本あたりの画像は3枚まで（1枚を寄り・引きで切り抜いて複数カットに使い回す）に抑えてあります。

## 自分で撮りたい回
スマホで撮った写真や動画を、同じく番号の名前で「素材/各回」に入れればそれが使われます。

## ルール
- 投稿時は TikTok の「AI生成コンテンツ」ラベルを必ずON（投稿文にも「※AI生成映像です」が入る）
- AI映像で「手作り」「制作〇時間」とは言わない
- 他人の動画・画像の転載は禁止（著作権侵害＋TikTokが「オリジナルでない」としておすすめに載せない）

# 使うサイト・AIツール

## 必須（無料〜低コストで回る構成）
| 用途 | ツール | 役割 | 費用目安 |
|---|---|---|---|
| AI社員の本体 | **Claude（Claude Code / claude.ai アプリ）** | 調査・台本・構成・編集指示・品質チェック・進行管理 | Pro/Max プラン |
| 自動書き出し | **GitHub Actions**（このリポジトリ） | plan.json を push すると自動で動画化→ドライブ納品 | 無料枠で十分 |
| 素材・納品置き場 | **Google ドライブ**「ミニチュアの世界」 | 素材/ と 完成動画/ | 無料15GB |
| 投稿・予約・分析 | **TikTok Studio**（PCブラウザ） | 予約投稿（最大10日先）・アナリティクス | 無料 |

## あると強い（必要になったら追加）
| 用途 | ツール | ポイント |
|---|---|---|
| 仕上げ編集 | **CapCut**（PC/スマホ） | 自動書き出し後にトレンド音源・エフェクトを足したい時。TikTokと同じ会社で相性◎ |
| 自動字幕 | **Vrew** | しゃべりを入れる回の文字起こし→テロップ化 |
| AI画像（素材） | **Nano Banana（Gemini）/ ChatGPT画像生成 / Midjourney** | 「ミニチュアジオラマ・マクロ撮影・横に1円玉」のプロンプトで素材化 |
| AI動画（素材） | **Veo（Google）/ Kling / Sora / Hailuo** | 画像→3〜5秒の動きに。AIラベル必須 |
| ナレーション | **ElevenLabs / VOICEVOX** | ハイテンション実況ボイス（VOICEVOXは無料・クレジット表記要） |
| 撮影機材 | スマホ＋**マクロレンズ（2,000円前後）**＋リングライト | ミニチュアは「寄り」と「光」で9割決まる |

## 使わないもの
- 自動投稿ツール（非公式API）: アカウント凍結リスク。投稿は TikTok Studio の予約投稿で十分。

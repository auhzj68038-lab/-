# 使うサイト・AIツール

## 必須（無料〜低コストで回る構成）
| 用途 | ツール | 役割 | 費用目安 |
|---|---|---|---|
| AI社員の本体 | **Claude（Claude Code / claude.ai アプリ）** | 調査・台本・構成・編集指示・品質チェック・進行管理 | Pro/Max プラン |
| 自動書き出し | **GitHub Actions**（このリポジトリ） | plan.json を push すると自動で動画化→ドライブ納品 | 無料枠で十分 |
| 素材・納品置き場 | **Google ドライブ**「ミニチュアの世界」 | 素材/ と 完成動画/ | 無料15GB |
| 投稿・予約・分析 | **TikTok Studio**（PCブラウザ） | 予約投稿（最大10日先）・アナリティクス | 無料 |
| AI画像（素材の主力） | **Gemini API（Nano Banana = gemini-2.5-flash-image）** | 全カットのミニチュア画像を9:16で生成。モデルは `GEMINI_IMAGE_MODEL` で新型に切替可 | 1枚 約6円 |
| AI動画（見せ場） | **Seedance 2.0 fast（fal.ai 経由）** | 画像→4秒の動画。1本2カットまで | 1秒 約36円 |
| フリー素材 | **Pexels API** | 実写の手元・背景など（商用可・クレジット自動記載） | 無料 |
| 左腕 | **Claude のルーチン（Routines）** | 毎週土曜に自動起動して企画〜構成まで | Claude のプラン内 |

## あると強い（必要になったら追加）
| 用途 | ツール | ポイント |
|---|---|---|
| 仕上げ編集 | **CapCut**（PC/スマホ） | 自動書き出し後にトレンド音源・エフェクトを足したい時。TikTokと同じ会社で相性◎ |
| 自動字幕 | **Vrew** | しゃべりを入れる回の文字起こし→テロップ化 |
| 別の動画AI | **Veo（Google）/ Kling / Seedance 2.5** | fal.ai にある機種なら `FAL_VIDEO_ENDPOINT` を変えるだけで切替可 |
| ナレーション | **ElevenLabs / VOICEVOX** | ハイテンション実況ボイス（VOICEVOXは無料・クレジット表記要） |
| 撮影機材 | スマホ＋**マクロレンズ（2,000円前後）**＋リングライト | ミニチュアは「寄り」と「光」で9割決まる |

## 使わないもの
- 自動投稿ツール（非公式API）: アカウント凍結リスク。TikTok公式の投稿APIは審査が必要で、未審査だと「非公開」でしか投稿できない。投稿は TikTok Studio の予約投稿（週1回まとめて15分）が最も安全で速い。
- 他人のTikTok/YouTube動画のダウンロード・転載: 著作権侵害＋おすすめに載らなくなる。

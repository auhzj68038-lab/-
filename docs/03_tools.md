# 使うサイト・AIツール

## 使うもの（すべて無料枠・カード登録なし）
| 用途 | ツール | 役割 | 費用 |
|---|---|---|---|
| AI社員の本体 | **Claude**（今の月額プラン） | 調査・台本・構成・素材オーダー表・品質チェック | プラン内 |
| AI画像 | **Geminiアプリ**（Nano Banana） | オーダー表のコピペ文で画像を作る | 無料（1日の回数制限あり） |
| AI動画（任意） | **Dreamina**（CapCut／Seedance搭載） | 見せ場の画像を数秒の動画に | 毎日の無料クレジット内（無料版は透かし入り） |
| 自動書き出し | **GitHub Actions** | 素材が入ったら自動で動画化→ドライブ納品 | 公開リポジトリは無料・無制限 |
| 素材・納品置き場 | **Googleドライブ** | 素材/ と 完成動画/ | 無料15GB |
| 投稿・分析 | **TikTok Studio**（PC） | 予約投稿（最大10日先）・アナリティクス | 無料 |
| 仕上げ（任意） | **CapCut** | トレンド音源やエフェクトを足したい時 | 無料版でOK |

## 将来の拡張（有料・今は使わない）
| ツール | できること | 目安 |
|---|---|---|
| Gemini API | 画像づくりも全自動に | 1枚 約6円 |
| Seedance API（fal.ai） | 動画化も全自動に | 1秒 約36円 |
GitHub の金庫に鍵を入れたときだけ動く設計なので、入れなければ課金はゼロです。

## 使わないもの
- 自動投稿ツール（非公式API）: アカウント凍結リスク。TikTok公式の投稿APIは審査が必要で、未審査だと「非公開」でしか投稿できない。投稿は TikTok Studio の予約投稿（週1回まとめて15分）が最も安全で速い。
- 他人のTikTok/YouTube動画のダウンロード・転載: 著作権侵害＋おすすめに載らなくなる。

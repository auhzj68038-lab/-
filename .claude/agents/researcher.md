## 仕事
1. `docs/01_market_research.md` と `content/` 配下の過去回を読み、既出ネタと勝ちパターンを把握する。
2. WebSearch で直近2週間の「ミニチュア / ジオラマ / ミニチュアフード / tiny world / miniature」系の伸びている投稿・音源・ハッシュタグ・季節イベントを調べる（TikTok本体は取得できない場合があるので、まとめ記事・YouTube Shorts・Instagram・ニュースも使う）。
3. 次の型から企画を3本出す。各企画に「フック（最初の1.5秒の一言）」「オチ（コメントを誘う問い）」「必要な撮影素材（5〜7カット）」「実写 or AI生成」を書く。
   - 世界一小さい〇〇シリーズ / サイズ比較（1円玉・指先・米粒） / 小人の1日（Vlog風） / ビフォーアフター（ゴミ→ミニチュア） / 季節イベントのミニチュア化 / コメント募集→作るリクエスト回
4. 結果を `content/<YYYY-MM-DD>_epNNN_<英字スラッグ>/research.md` に保存する（エピソード番号は content/ の最大+1）。

## ルール
- 出典URLを必ず書く。推測は「推測」と明記。
- 1日30分以内で撮れる企画を優先（副業前提）。
- 他人の動画の丸パクリは禁止。型は借りても題材と見せ方はオリジナルに。

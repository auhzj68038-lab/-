# 1本作る流れ（社長=ユーザーの作業は最後の確認と投稿だけ）

引数: $ARGUMENTS（テーマ・本数の指定。無ければおまかせで1本）

1. **市場調査** — `researcher` サブエージェントに依頼し、企画3本を research.md に出させる。
   テーマ指定があればそれを優先。本数指定があれば企画も本数分のフォルダを作る。
2. **台本** — `scriptwriter` サブエージェントで script.md と caption.txt を作る。
3. **構成** — `director` サブエージェントで plan.json を作り qa.py の ERROR を 0 にする。社長が「撮影する」と言わない限り全カットAI素材（gen）で指定する。
4. **動画作成** — `editor` サブエージェントでプレビュー→目視→本番書き出し。
5. **確認** — `qa` サブエージェントで qa_report.md。差し戻しなら該当工程に戻す（最大2周）。
6. **納品** — `publisher` サブエージェントで post_checklist.md を作り、コミットして
   `git push -u origin <現在のブランチ>`。GitHub Actions がドライブへ納品する。

最後に社長へ、以下だけを短く報告する:
- 企画タイトルとフック
- 撮影が必要なカット一覧（素材が未着の場合。ドライブ「素材/<エピソードフォルダ名>/」に 01_xxx.mp4 の名前で入れてもらう）
- 納品先URLと投稿予定日時
